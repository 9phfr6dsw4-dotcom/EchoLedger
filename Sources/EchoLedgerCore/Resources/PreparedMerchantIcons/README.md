# Prepared merchant artwork

50 transparent sRGB RGBA PNGs, each 192 × 192 pixels, for small app and PDF presentation. Company colors are retained; generated category symbols use varied colors. The catalog records artwork type, source and SHA-256. Supplied company artwork has unverified original provenance; see ARTWORK-SOURCES.md and the included source licenses. Company marks belong to their respective owners.

This directory is copied independently of the generated MerchantIcons collection, so regenerating that collection does not delete these files. Prepared names take precedence over older catalog artwork. Generic semantic matches describe a payment purpose and never identify a company or change a transaction. Personal names and private statement aliases are not included.
