# EchoLedger 0.2.0

- New cream-and-forest design with clearer reports, grouped settings, a more inviting Ask screen, and useful actions when Review is complete.
- New echo icon in the modern macOS icon format, plus a Finder-compatible icon.
- Assign accounts and imported additional cards to people, shared household spending, or an unassigned group.
- Select one or several people in Reports and Transactions. Shared spending is included only when selected, and the whole-household total counts every expense once.
- Assign individual or selected transactions, with Undo. New account defaults preserve past assignments; explicitly apply defaults to past transactions when needed.
- Optional personal spending allowances and household context on filtered reports.
- A separate demo workspace with fictional people and accounts for exploring and sharing the app.
- Saved data from earlier versions remains supported. Transfers, refunds, pending charges, and review notes retain their existing calculation rules.

## Install
Quit EchoLedger, move the old app to the Trash, then put the new EchoLedger.app in Applications. If macOS blocks the ad-hoc signed build, open System Settings → Privacy & Security → Open Anyway. Avoid uninstaller utilities; your database remains in Application Support. An optional backup is available in Settings → Data & Backups.
