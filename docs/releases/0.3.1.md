# EchoLedger 0.3.1

- Choose a PDF report style before saving: **Signature** (elegant editorial), **Everyday** (friendly panels and visual charts), or **Precision** (formal statement). EchoLedger remembers your last choice.
- All styles use the report's current people/card scope and calculations, including refunds, pending charges, and items needing review. Each includes category and merchant detail, spending assignments, income sources, recurring charges, and coverage notes.
- Measured text and automatic page breaks keep long names, tables, and notes readable. Continuation pages repeat the report scope, table headings, and page numbers. Income sources and recurring charges are no longer limited to the first few rows.
- Month labels now sit below the monthly charts, separated from bars and amount labels.
- Preserves the card-user options, small-window improvements, and saved-data behavior from 0.3.0.

## Install
Quit EchoLedger, move the old app to the Trash, and put the new EchoLedger.app in Applications. If macOS blocks it, use System Settings → Privacy & Security → Open Anyway. Avoid uninstaller utilities; your saved ledger remains in Application Support.

## Try it
Export the same report in all three styles; confirm the selected people/cards, figures, and notes agree. Check the month labels on Overview and Trends.
