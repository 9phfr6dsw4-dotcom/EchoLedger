# EchoLedger 0.4.1

- **Merchant icons in the Mac app.** Compact icons sit beside merchant names in Transactions, the detail panel, merchant and income reports, expanded category rows, recurring charges, and report drill-downs. The existing Warm Ledger layout and category colors remain in place.
- **Icons in exported PDFs.** Signature, Everyday, and Precision reports embed the same merchant artwork beside merchant, income-source, and recurring-payment rows. Long names still wrap and continue onto further pages.
- **Entirely offline.** EchoLedger automatically matches resolved merchant names against 3,115 bundled brand marks. Fictional demo merchants and businesses outside the collection use category symbols or initials. No merchant names or transaction details are uploaded, and no logo-service account is needed.
- All merchants and transactions remain included regardless of logo coverage. This update does not change your saved ledger, transaction classifications, or report totals.

## Install

Quit EchoLedger, move the old app to the Trash, and put the new EchoLedger.app in Applications. If macOS blocks it, use System Settings → Privacy & Security → Open Anyway. Avoid uninstaller utilities; your saved ledger remains in Application Support.

## Optional checks after installing

Look at Transactions and Reports → Merchants, select a transaction to see its detail icon, and export a report in any of the three PDF styles. Demo merchants use neutral symbols. Your figures should match the previous version.
