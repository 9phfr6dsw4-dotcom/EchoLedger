# EchoLedger 0.4.2

- **Fix an installed-app crash when merchant icons first load.** The icon catalog now finds its artwork bundle inside the installed app's Contents/Resources folder instead of using SwiftPM's fatal resource accessor.
- **Safe fallbacks.** Missing or unreadable artwork now gives an empty catalog and neutral merchant symbols or initials rather than terminating the app.
- **Stronger release checks.** CI opens the extracted app directly in a fictional Transactions workspace with the build directory hidden, checks bundled icon loading and a rendered window, and exports all three PDF styles before publishing.

Your saved ledger, merchant classifications, and report figures are unchanged. No data reset or re-import is needed.

## Install

Quit EchoLedger, unzip the download, and replace EchoLedger.app in Applications. If macOS blocks it, use System Settings → Privacy & Security → Open Anyway. Avoid uninstaller utilities; your saved ledger remains in Application Support.
